API contract — v1

POST /api/v1/institution-submissions

Send a JSON body with academic_year and a records array. Each record requires institutional_enrolment_id, institution_student_id, student_name, programme_code, programme_name, and enrolment_status. Optional student_category (domestic, nri, oci, foreign_national, unknown) and seat_type (regular, supernumerary) fields support monitoring only; they default to unknown/regular and do not apply regulatory allocation rules. Use an Authorization: Bearer … header and a unique Idempotency-Key header. Maximum 5,000 records per request.

Repeated requests with the same key and same content return the original batch. Reusing a key with different content returns a conflict. Identical content under a new key is also rejected. This is an integration prototype, not an official endpoint.
